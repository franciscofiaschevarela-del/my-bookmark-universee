Datos y copias de seguridad

Cómo funciona

Privacidad

Esta página no usa servidor ni claves API y su política de seguridad bloquea cualquier conexión de red. Tus favoritos nunca salen del dispositivo. Por eso las miniaturas de los sitios no se descargan: se usa el favicon que ya venía en tu archivo y una tarjeta de color de respaldo. Podés poner tu propia imagen en cada enlace.

Guardado local

Los datos se guardan en el almacenamiento del navegador (IndexedDB) de este dispositivo y de este navegador. No se sincronizan solos: la compu y el iPad tienen bibliotecas separadas.

  • Para pasar tu biblioteca de un dispositivo a otro: Exportar copia (.json) y luego Importar en el otro.
  • Safari puede borrar datos de sitios que no abrís durante ~7 días. Si agregás la página a la pantalla de inicio del iPad (Compartir → “Añadir a pantalla de inicio”) queda protegida de esa limpieza.
  • Borrar “datos de sitios web” o el historial puede eliminar la biblioteca. Hacé copias periódicas.
